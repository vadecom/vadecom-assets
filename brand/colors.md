# VadeCom Colour Palette

This file is the single authority for colour in every VadeCom asset: web, social,
print, decks, proposals, ads, motion, and anything generated by an AI tool.
If another file, template, brand kit or design disagrees with this file, that
other thing is wrong and is to be fixed.

## 1. The palette is a closed set

Only the six values below may appear in a VadeCom asset. Any colour not listed
here is **prohibited**.

- No "close enough" values. `#0060B0` is not `#005CB4`. [off-palette]
- No eyedropper sampling from existing designs, screenshots, logos or reference
  images. Existing work is measured against this file, never the reverse.
- No new hues, tints or shades. The one permitted derivation is an **opacity
  step of `#005CB4`** (see §3).
- Colours from earlier guides that are not in this table are prohibited,
  including `#FFC71B` (yellow). [off-palette]

| Token           | Hex       | RGB           | Role                                   |
|-----------------|-----------|---------------|----------------------------------------|
| `blue-base`     | `#005CB4` | 0, 92, 180    | **Primary.** The VadeCom blue.         |
| `red-accent`    | `#C9002B` | 201, 0, 43    | Accent only.                           |
| `navy-ink`      | `#001A3D` | 0, 26, 61     | Text only.                             |
| `surface-white` | `#FFFFFF` | 255, 255, 255 | Background, cards, panels.             |
| `surface-soft`  | `#F5F7FA` | 245, 247, 250 | Background.                            |
| `grey-500`      | `#8A94A6` | 138, 148, 166 | Secondary, non-text and large-text use.|

## 2. Rules per colour

### `blue-base` — `#005CB4`
- The primary colour. Fills, CTAs (buttons, links), key graphics, charts' first
  series, and icon fills.
- **The only approved coloured background.** A slide, section, card or social
  post that is not white or soft is blue-base.
- Text on blue-base is `surface-white` only. Never `navy-ink`, `red-accent` or
  `grey-500` on blue-base.

### `red-accent` — `#C9002B`
- Accent only. Approved uses: **one** emphasised word per headline, underlines,
  alert/notification dots, a single highlighted number.
- Stays under **~5% of the canvas**. Never a background, never a fill for large
  shapes, never body text, never more than one emphasised word per headline.
- Red never sits on blue-base (they do not contrast: 1.10:1).

### `navy-ink` — `#001A3D`
- **Text only.** Headlines and body copy on `surface-white` and `surface-soft`.
- **Never a background**, never a fill, never a large shape, never a gradient
  stop. A "dark" section uses `blue-base`, not navy.

### `surface-white` — `#FFFFFF`
- Default background. Cards, panels, and text on `blue-base`.

### `surface-soft` — `#F5F7FA`
- Secondary background for alternating sections, table stripes, input fields
  and content wells. Never as text.

### `grey-500` — `#8A94A6`
- Secondary uses: dividers, borders, disabled states, icon strokes,
  placeholder text, captions and metadata rendered as large text
  (24px+ regular, or 18.66px+ bold).
- **Not for body text or headlines.** Grey-500 on white is 3.06:1, which fails
  WCAG AA for normal-size text. Body copy is `navy-ink`.
- Never a background, never a fill for large shapes.

## 3. Opacity steps of `blue-base`

- `blue-base` may be used at any opacity over `surface-white` or `surface-soft`
  (backgrounds of sections, hover states, chart fills, subtle tints).
- Declare the step as `#005CB4` **with an alpha** — `rgba(0, 92, 180, 0.12)`,
  `#005CB41F`, "blue-base 12%". Do not flatten it to a new opaque hex:
  what 12% blue-base looks like on white is not a palette colour. [off-palette: `#E5EFF7`]
- Opacity steps are for `blue-base` only. No opacity steps of red, navy or grey.

## 4. Approved pairings

| Foreground      | Background      | Ratio   | Verdict                          |
|-----------------|-----------------|---------|----------------------------------|
| `navy-ink`      | `surface-white` | 17.28:1 | Body and headline text           |
| `navy-ink`      | `surface-soft`  | 16.10:1 | Body and headline text           |
| `surface-white` | `blue-base`     | 6.58:1  | Text on blue                     |
| `blue-base`     | `surface-white` | 6.58:1  | Links, CTAs, icons               |
| `red-accent`    | `surface-white` | 5.97:1  | Emphasised word, alert dot       |
| `grey-500`      | `surface-white` | 3.06:1  | Large text, dividers, icons only |
| `navy-ink`      | `blue-base`     | 2.63:1  | **Prohibited**                   |
| `red-accent`    | `blue-base`     | 1.10:1  | **Prohibited**                   |

## 5. Proportions on a typical canvas

- `surface-white` / `surface-soft`: most of the canvas.
- `blue-base`: the dominant colour — hero blocks, CTAs, key graphics, or the
  full background of a blue slide/post.
- `navy-ink`: all text on light surfaces.
- `red-accent`: under ~5%.
- `grey-500`: structural details only.

the consistency check fails if they differ.
