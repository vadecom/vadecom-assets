# VadeCom logo files

This file is an **index** of the logo assets in this folder. Logo usage rules
(clear space, minimum size, which variant goes on which background, misuse) are
**not yet decided** — this file is a draft until they are.

One rule already binds every logo placement: the background behind a logo is a
palette colour from [`brand/colors.md`](../colors.md) — `surface-white`,
`surface-soft`, or `blue-base`.

"Light" and "Dark" name the **colour of the logo artwork**: *Light* is the
white wordmark (for `blue-base` backgrounds), *Dark* is the blue wordmark (for
`surface-white` / `surface-soft` backgrounds). The "Light" horizontal/square/
circle PNGs ship with the blue background baked in; the "Dark" ones ship on
white.
